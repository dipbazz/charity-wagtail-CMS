The menu is now the same five sections on every charity's site, in this order and with these
names in each language: About us, Appeals, Stories, Get involved and Contact. A moderator chooses
the page each one links to in the new **Site settings → Menu** tab, which names any section the
menu leaves out because no page is chosen, or its page isn't published or is behind a password or
login. Ticking "Show in menus" no longer adds a page to the menu. Appeals takes only the appeals
page, Stories only the stories page and the Donate button only the Donate page, and one page can't
be two sections ([#171](https://github.com/dipbazz/trayi/issues/171)).
