# Decisions

Short records of choices already made and why, so nobody has to rediscover the reasons or undo
a choice by accident. Each says what was decided, why, and what it costs.

When a pull request makes a choice that someone might later question (a new dependency, a
hosting change, a rule everyone must follow), add a record here in the same pull request. To
reverse a decision, add a new record that replaces the old one, and mark the old one
"Replaced by …" rather than deleting it.
