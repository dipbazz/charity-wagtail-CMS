# Editor guide

A guide for the charity's own team: how to write pages, run appeals, publish news, manage
supporters and change the site-wide banner in the Wagtail admin.

This guide hasn't been written yet; it's planned under the
[Documentation epic](https://github.com/dipbazz/Charity-wagtail-CMS/issues/74). Until then:

- [Permissions](../topics/permissions.md) says what editors and moderators can each change.
- Wagtail's own [editor manual](https://guide.wagtail.org/) covers the admin in general.
